This zip-file includes the data and programs used for replicating results in "Islamic Rule and the Emancipation of the Poor and Pious" by Erik Meyersson

*************Contents*************

A) Programs:

Author-created programs

	rdprog_cols1_se.do - Program for making binned graphs.

Non-author programs used in do-files

	RDOB: Program created for Imbens and Kalyanaraman (2009)
		Source: http://www.economics.harvard.edu/faculty/imbens/software_imbens

	DCDENSITY: Program created for McCrary (2008)
		Source: http://www.econ.berkeley.edu/~jmccrary/DCdensity/


B) STATA DATASETS:

	regdata0.dta - Municipal-level dataset 


C) DOFILES:

	tables_R4_final.do - Produces all the tables in paper.
	graphs_R4_final.do - Produces all figures in paper.
